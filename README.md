# VM Lounge 2026

Mobilvennlig VM 2026 betting-/tippekonkurranse med falsk valuta.

## Innhold

- Home page
- Betting page med betslip
- Forum page
- Chat page
- Profil page
- Sjakk page

## GitHub Pages

Last opp disse filene i repoet ditt:

- index.html
- styles.css
- app.js

Gå til Settings → Pages → Deploy from branch → main → /root.

## Viktig

Denne versjonen bruker localStorage. Den fungerer direkte, men data deles ikke live mellom venner før vi kobler på Firebase.
